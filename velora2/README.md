# Velora 2 — 品牌館提案站

維羅拉國際的下一版形象網站提案。回答的問題是：
**香氛／絲巾／銀飾，和手機包，怎麼放進同一個網站而不像兩家公司。**

## 怎麼跑

沒有建置步驟、沒有 `npm install`、沒有任何依賴。

```bash
cd velora2 && python -m http.server 5273 --bind 127.0.0.1
# → http://127.0.0.1:5273
```

部署就是把整個 `velora2/` 丟上任何靜態主機。沒有後端，沒有後台。

---

## 整合方式：以品牌館排，不做論述

骨架是**「我們代理哪些品牌」**，不是「我們賣哪些品類」。
VUCA、SAINTMARI、手機包各自成一塊，彼此只用一條髮絲線隔開。

這是刻意的取捨。上一版把兩大類講成「同一本目錄的兩個章節」，
用羅馬數字、書脊章節牌去論證它們是一家人 —— 綁得太緊，
而且客人本來就不會問「為什麼香氛跟手機殼在同一個網站」。
代理商同時代理不相干的品牌，本來就很正常。

所以現在網站不解釋，只呈現：

1. **主視覺的品牌索引**就是全站骨架 —— 三家並列，不編號、不分章。
2. **一家一塊**，各自帶自己的介紹、品類與選件。第三家還沒公布，
   位置留著但不假裝它已經有名字（字標處排的是「品牌待公布」，
   而且刻意用 CJK 臉，和已有字標的兩家分開）。
3. **〈選物準則〉講的是維羅拉怎麼決定要不要代理一條線**，
   不是講商品彼此像不像。三條準則對三家一體適用。

留下來的是**材質標記**：每件商品，不論真絲長巾或手機包，
都帶同一張規格表（材質、尺寸、收邊）。那是選品標準的體現，
不是「它們是一類」的主張。

書脊（左邊那條金線）也留著 —— 它是既有設計語彙的一部分，
桌機上隨捲動報出目前看到哪一家。

## 沿用的設計系統

色票、字體、金色規則、影像板全部沿用既有的**雕版目錄**語彙
（見 `.claude/skills/velora-design/` 與 `design/spec/00-design-system.md`），
因為客戶已經認可這個方向。Velora 2 新增的只有書脊位置牌與材質標記表。

三條沒有妥協的硬性規則：

| 規則 | 落實 |
|---|---|
| 展示頁不出現價格、購物車、下單 | 唯一轉換是 LINE；頁尾明寫價格於 LINE 洽詢 |
| `#C5A880` 不承載文字 | 只做線、框、菱形飾釘。所有金色文字用 `#7E6239` |
| 不使用 Tailwind | 設計 token 直接寫在 `assets/style.css` |

**全站文字在四種背景（`#fdfbf7` / `#f8f6f0` / `#f2efe9` / `#ebe7df`）上
最低對比 4.60:1，全數通過 WCAG AA。** 包含金色文字與最淡的註記色。

LINE 按鈕滑過時翻成墨底金字（16.1:1），不用金底白字 ——
白字壓在 `#C5A880` 上只有 2.26:1。

## 行動優先

CSS 預設樣式就是手機版，`min-width` 才往上加：

- **預設（手機）** 單欄。書脊是一條髮絲線，不掛位置牌 ——
  標籤在髮絲線上沒有落腳處，浮起來會壓到內文。
  手機不缺這個資訊：品牌字標就在眼前。
- **≥ 680px** 品類列橫排、商品兩欄、準則與品牌三欄。
- **≥ 1040px** 書脊變成真正的書口，位置牌立起來直排；
  主視覺變扉頁排法（大標題佔左欄，導言貼著標題底線收在右欄）；
  區段頭與品牌頭都是兩欄（標題左、導言右），全站同一個形狀。

## 三語

繁中 / English / 한국어。首次進站依瀏覽器語言，之後記在 `localStorage`。

**沒有字典表。** 譯文直接寫在 HTML 的 `data-en` / `data-ko` 屬性上，
中文是 DOM 的原始內容：

```html
<h4 data-en="Necklace" data-ko="목걸이">項鍊</h4>
```

好處有二：關掉 JS 仍是一個完整的中文站（內容都在 HTML 裡）；
改文案只要改一個地方，不必在兩個檔案之間對照 key。

拉丁字與 CJK 是兩個語域，語言換了字體跟著換
（`html[lang='en']` 切到 Marcellus）。韓文交給系統字
（Malgun Gothic / Apple SD Gothic Neo），不為此多載一套 Noto Serif KR ——
省下的位元組比較值錢。

## 資安

| 措施 | 位置 |
|---|---|
| CSP `default-src 'none'`，逐項開放 | `index.html` `<meta http-equiv>` |
| 無內聯腳本、無內聯樣式（CSP 未開 `unsafe-inline`） | 全站沒有 `<style>`、沒有 `style=""`、沒有 `onclick=""` |
| 全站零 `innerHTML`，只用 `textContent` | `assets/app.js` |
| `localStorage` 讀回的值先比對白名單才用 | `setLang()` |
| 無 `fetch`、無第三方腳本、無追蹤碼 | CSP `connect-src 'none'` 且程式也真的不連 |
| 外連一律 `rel="noopener noreferrer"` | LINE 連結 |
| `referrer` 設為 `no-referrer` | `<meta name="referrer">` |
| 不可被嵌入（點擊劫持） | CSP `frame-ancestors 'none'` |
| 零 npm 依賴 | 沒有供應鏈，沒有 `node_modules` |

**機密紅線**：Excel 的 FOB 出口單價（欄 P/Q）、供應商業務姓名與手機（欄 G）、
事業登記號（欄 F）**沒有進入本目錄任何一個檔案**。價格完全不落地到前端。
稽核用 `node ../check-public.mjs`。

字型是唯一的外部來源（`fonts.googleapis.com` / `fonts.gstatic.com`）。
要做到零第三方請求，把字型檔下載進 `assets/fonts/`、
改寫成本地 `@font-face`，然後把 CSP 的 `style-src` 收成 `'self'`、
移除 `font-src` 的外部來源。

## 待替換：第三家（手機包）

**HOUSE · 03 的品項全部是版面示意，不是真實商品。**
品名與規格（頭層牛皮、麂皮絨加襯、植鞣牛皮）是為了讓版式站得住
而寫的合理值，不代表任何已談定的貨。頁面上放了一行〈編按〉明講，
定案後刪掉那行即可。

品類設定為**手機包 / 背帶 / 保護殼** —— 依據是維羅拉自己的
臉書粉專標題「維羅拉國際有限公司 - 韓國設計師手機包」。
若實際主力是保護殼與充電配件，品類與 ref 碼要一併改。

照片還沒有，所以影像板留成**空版**（「圖片製版中」＋索引碼），
不放圖庫照或示意圖。空著比放假的誠實，而且正好合這本目錄的語彙 ——
校樣上等著上版的位置。

定案後要改的地方（都在 `index.html` 的 `<article class="house" id="mobile">` 裡）：

1. `h3.tbd` 換成真正的品牌字標，並移除 `class="tbd"`
2. `.loc` 產地與品類
3. `.say` 品牌介紹（三語）
4. `.cats` 的品類與 ref 碼
5. 三張 `article.card` 的品名、描述、材質標記（三語）
6. 把 `<span class="plate pending">…</span>` 換成
   `<span class="plate"><img src="assets/media/…"></span>`，
   去背圖再加 `is-cutout`
7. 刪掉 `<p class="proof">` 編按
8. 主視覺 `.hero-index` 第三項的「品牌待公布」
9. `assets/app.js` 的 `CHAPTERS.mobile` 改成品牌名

## 動態

只有一個：載入時書脊由上往下描出來（900ms）。
其餘是安靜的滑過狀態。`prefers-reduced-motion` 全部關掉。

原本有一組捲動揭示（區塊逐一淡入），拿掉了 ——
內容在揭示前是 `opacity:0`，只要 observer 沒觸發整頁就是空白，
用一個裝飾效果換「內容可能不見」的風險並不划算。
動態集中在書脊那一次，比散在各段更有份量。

## 素材

`assets/media/` 只放**實際被引用**的六張圖。`velora2/` 是純靜態目錄，
沒有打包器做搖樹 —— 放進去的每個檔案都會被上傳、都能被公開存取，
即使頁面沒有引用它。加圖時從 `velora-frontend/public/media/` 取
（那裡是 `design/build-assets.py` 的產出，可重生），
不要手動改圖檔名。
