# Velora 2 — 韓系低調奢華提案站

維羅拉國際的下一版形象網站提案。零依賴純靜態，行動優先，三語。

```bash
cd velora2 && python -m http.server 5273 --bind 127.0.0.1
# → http://127.0.0.1:5273
```

沒有建置步驟、沒有 `npm install`、沒有後端、沒有後台。
部署就是把整個 `velora2/` 丟上任何靜態主機。

## 骨架：四個品類

導覽與版面都以品類為單位，不是以品牌為單位：

| 品類 | ref | 內容 |
|---|---|---|
| 香氛 | FRG | VUCA 居家擴香，5 款香調 |
| 絲巾 | SLK | SAINTMARI 真絲長巾，13 款印花 |
| 飾品 | JWL | SAINTMARI 925 純銀首飾 + 絲巾扣 |
| 手機包 | BAG | 韓國設計師手機包（待定案） |

**這一類叫「飾品」而不是「配件」是刻意的。**
手機包本身就是配件；如果有一類叫「配件」，讀者會問手機包為什麼不在裡面。
「飾品」是戴在身上的，「手機包」是背在身上的，兩個詞不會互相吃掉。

品牌沒有消失，只是換了位置：**每張商品卡的索引碼右邊標出這件出自哪一家**
（`VL · SLK · 001` … `SAINTMARI`），下方另有〈關於 · 代理品牌〉一節
交代三家的背景。分類負責瀏覽，品牌負責信任感。

## 韓系低調奢華：靠層次，不靠白底加細線

這一版針對三個回饋重做，三件事其實是同一個根源 ——
上一版太接近西式白底編輯風，缺了韓系那種暖調紙感與厚實字重。

### 1 底色不再是白的

| | 舊 | 新 |
|---|---|---|
| 紙色 | `#FDFBF7` | `#F3EDE2` |
| 亮度 | 96.6% | **85.1%** |

差十一個百分點，是看得出來的暖調紙。紙紋也從 `0.055` 加重到 `0.075`。

### 2 整頁由淺到深落底

韓系低調奢華靠的是層層疊上去的暖調，不是一片白底加細線。
所以頁面色調從上往下逐級加深，最後收在一塊暖褐暗塊：

```
紙   #F3EDE2   主視覺、四個品類分區
米帶 #ECE5D8   代理品牌
版面 #E4DBCA   選物準則
暗塊 #2B2419   LINE 洽詢 + 頁尾   ← 整頁的低音
```

暗塊用**暖褐**而不是黑 —— 黑會把整頁的暖調切斷。
LINE 按鈕在暗塊上滑過時翻成金底暗字（8.49:1）。

四個品類分區之間不換底色，只用一條髮絲線隔開：分區換的是內容，不是紙。

### 3 字級整體放大約一成五（手機優先）

客戶已在手機上實測回報過兩次太小，這一版直接給足：

| | 舊 | 新 |
|---|---|---|
| 內文 body | 15px | **17px** |
| 商品說明 `.say` | 14px | **15.5px** |
| 導言 `.lede` | 14.5px | **16px** |
| 規格表 `.hall` | 11.5px | **13px** |
| 索引碼 `.ref` | 10.5px | **12px** |
| 商品名 `.card h3` | 20px | **23px** |
| 區段標題 `h2` | 26–40px | **30–44px** |

## 設計系統

沿用既有的**雕版目錄**語彙（見 `.claude/skills/velora-design/`
與 `design/spec/00-design-system.md`）：左邊一條貫穿全頁的金色書脊、
雙層金框影像板、菱形飾釘、`VL · SLK · 001` 索引碼、
每件商品一張材質標記規格表。

字體（兩個語域，刻意不同臉）：

- Display Latin — **Marcellus** 400，不低於 26px
- Display CJK — **Noto Serif TC** 200
- Body — **Noto Sans TC** 300，行距 1.85–1.95
- Index / Data — **DM Mono** 400，只承載編號與規格
- 韓文交給系統字（Malgun Gothic / Apple SD Gothic Neo），
  不為此多載一套 Noto Serif KR

三條沒有妥協的硬性規則：

| 規則 | 落實 |
|---|---|
| 展示頁不出現價格、購物車、下單 | 唯一轉換是 LINE；頁尾明寫價格於 LINE 洽詢 |
| `#C5A880` 不承載文字 | 只做線、框、菱形飾釘 |
| 不使用 Tailwind | 設計 token 直接寫在 `assets/style.css` |

## 行動優先

CSS 預設樣式就是手機版，`min-width` 才往上加：

- **預設（手機）** 單欄。書脊是一條髮絲線，不掛位置牌 ——
  標籤在髮絲線上沒有落腳處，浮起來會壓到內文。
  手機不缺這個資訊：品類標題就在眼前。
- **≥ 680px** 品類索引橫排四欄、商品兩欄、準則與品牌三欄。
- **≥ 1040px** 書脊變成真正的書口，位置牌立起來直排；
  主視覺變扉頁排法（大標題佔左欄，導言貼著標題底線收在右欄）；
  區段頭、轉換區、頁尾都是兩欄，全站同一個形狀。

## 三語

繁中 / English / 한국어。首次進站依瀏覽器語言，之後記在 `localStorage`。

**沒有字典表。** 譯文直接寫在 HTML 的 `data-en` / `data-ko` 屬性上，
中文是 DOM 的原始內容：

```html
<h3 data-en="Necklace" data-ko="목걸이">項鍊</h3>
```

好處有二：關掉 JS 仍是一個完整的中文站（內容都在 HTML 裡）；
改文案只要改一個地方，不必在兩個檔案之間對照 key。

拉丁字與 CJK 是兩個語域，語言換了字體跟著換（`html[lang='en']` 切到 Marcellus）。

## 資安

| 措施 | 位置 |
|---|---|
| CSP `default-src 'none'`，逐項開放 | `index.html` `<meta http-equiv>` |
| 無內聯腳本、無內聯樣式（CSP 未開 `unsafe-inline`） | 全站沒有 `<style>`、`style=""`、`onclick=""` |
| 全站零 `innerHTML`，只用 `textContent` | `assets/app.js` |
| `localStorage` 讀回的值先比對白名單才用 | `setLang()` |
| 無 `fetch`、無第三方腳本、無追蹤碼 | CSP `connect-src 'none'` 且程式也真的不連 |
| 外連一律 `rel="noopener noreferrer"` | LINE 連結 |
| `referrer` 設為 `no-referrer` | `<meta name="referrer">` |
| 不可被嵌入（點擊劫持） | CSP `frame-ancestors 'none'` |
| 零 npm 依賴 | 沒有供應鏈，沒有 `node_modules` |

**機密紅線**：Excel 的 FOB 出口單價（欄 P/Q）、供應商業務姓名與手機（欄 G）、
事業登記號（欄 F）**沒有進入本目錄任何一個檔案**。價格完全不落地到前端。
稽核用 `node ../check-public.mjs`。

字型是唯一的外部來源（`fonts.googleapis.com` / `fonts.gstatic.com`）。
要做到零第三方請求，把字型檔下載進 `assets/fonts/`、改寫成本地 `@font-face`，
然後把 CSP 的 `style-src` 收成 `'self'`、移除 `font-src` 的外部來源。

## 待替換：手機包

**〈手機包〉的三件品項全部是版面示意，不是真實商品。**
品名與規格（頭層牛皮、麂皮絨加襯、編織織帶）是為了讓版式站得住而寫的
合理值，不代表任何已談定的貨。頁面上放了一行〈編按〉明講，定案後刪掉即可。

品類設定的依據是維羅拉自己的臉書粉專標題
「維羅拉國際有限公司 - 韓國設計師手機包」。
臉書相簿需要登入才看得到，程式抓不到圖 ——
照片請直接放進 `assets/media/`，或給我路徑我來處理。
拿得到供應商原始圖會比臉書上的好，臉書會重壓過。

照片還沒有，所以影像板留成**空版**（「圖片製版中」＋索引碼），
不放圖庫照或示意圖。空著比放假的誠實，而且正好合這本目錄的語彙 ——
校樣上等著上版的位置。

定案後要改的地方（都在 `index.html` 的 `<section id="phonebag">` 裡）：

1. 三張 `article.card` 的品名、描述、材質標記（三語）
2. `.ref` 裡的 `<em>品牌待公布</em>` 換成真正的品牌名
3. 把 `<span class="plate pending">…</span>` 換成
   `<span class="plate"><img src="assets/media/…"></span>`，
   去背圖再加 `is-cutout`
4. 刪掉 `<p class="proof">` 編按
5. 主視覺 `.hero-index` 手機包那一項的款數 `—`
6. 〈代理品牌〉的 `HOUSE · 03` 填上品牌

## 動態

只有一個：載入時書脊由上往下描出來（900ms）。
其餘是安靜的滑過狀態。`prefers-reduced-motion` 全部關掉。

原本有一組捲動揭示（區塊逐一淡入），拿掉了 ——
內容在揭示前是 `opacity:0`，只要 observer 沒觸發整頁就是空白，
用一個裝飾效果換「內容可能不見」的風險並不划算。

## 素材

`assets/media/` 只放**實際被引用**的九張圖。`velora2/` 是純靜態目錄，
沒有打包器做搖樹 —— 放進去的每個檔案都會被上傳、都能被公開存取，
即使頁面沒有引用它。加圖時從 `velora-frontend/public/media/` 取
（那裡是 `design/build-assets.py` 的產出，可重生），不要手動改圖檔名。

## 截圖

`design/shoot.mjs` 的坑在這裡同樣適用，另有一條：
**Chrome 命令列的視窗寬度有 504px 下限**，`--window-size=390` 拿不到手機視寬，
量到的會是 504。真手機寬度要用同源 iframe 承架取得，
或直接以 504px 驗證（仍在 680px 斷點之下，走的是同一套手機樣式）。
另外錨點截圖不可靠（平滑捲動與截圖搶時間），改用整頁擷取再裁切。
